# HOOK BANK

> Mỗi hook: viết ≤ 7 từ, nói trong ≤ 2s. Đo bằng tỉ lệ giữ chân 3s. Giữ thân + CTA cố định khi test.

| # | Hook | Kiểu | Nguồn cảm hứng | Video | Giữ chân 3s | Xem hết | CTR | Ghi chú |
|---|---|---|---|---|---|---|---|---|
| 1 | | nỗi đau | | | | | | |

## Các kiểu hook
- **Nỗi đau**: "Da xỉn màu dù đã skincare đủ bước?"
- **Kết quả**: "3 ngày, da sáng thấy rõ."
- **Phản biện**: "Đừng mua serum vitamin C nếu…"
- **Bí mật / người trong nghề**: "Dân spa không nói bạn điều này."
- **So sánh**: "289k vs 1 triệu 2: khác gì?"
- **Danh sách / vòng lặp mở**: "17 hiệu ứng Claude làm được" (reel mẫu)
- **POV / tình huống**: "POV: bạn vừa phát hiện…"
- **Bằng chứng xã hội**: "Lần trước làm cái này cháy mạng."
